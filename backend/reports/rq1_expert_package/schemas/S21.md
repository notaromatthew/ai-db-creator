Normalized university enrollment management system database schema in 3NF

TABLE students
  - id (INTEGER)  [PK, NN]
  - student_code (TEXT)  [UQ, NN]
  - name (TEXT)  [NN]
  - email (TEXT)  [UQ, NN]

TABLE courses
  - id (INTEGER)  [PK, NN]
  - code (TEXT)  [UQ, NN]
  - title (TEXT)  [NN]
  - credits (INTEGER)  [NN]

TABLE enrollments
  - id (INTEGER)  [PK, NN]
  - student_id (INTEGER)  [NN, FK->students.id]
  - course_id (INTEGER)  [NN, FK->courses.id]
  - semester (TEXT)  [NN]
  - grade (TEXT)  [NN]

RELATIONSHIPS
  - students.id [one_to_many] enrollments.student_id
  - courses.id [one_to_many] enrollments.course_id
