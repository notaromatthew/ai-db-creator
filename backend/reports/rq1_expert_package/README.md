# RQ1 expert-review package

This directory is generated by `backend/consolidate_rq1_schemas.py` from the existing `reports/benchmark` run.

- `schemas/S*.md` — 30 condition-blind schema printouts (one per run).
- `ratings_template.csv` — score sheet: dimensions D1..D5 (0-4 Likert) plus an optional free-text comment.
- `mapping.csv` — researcher-only key linking each code to dataset/condition/run. Keep separate until scoring is complete.

Distribution (protocol section 8): give experts the `schemas/` files, the blank score sheet and this protocol; give them random independent orderings. Never reveal `mapping.csv` before scoring is closed.
