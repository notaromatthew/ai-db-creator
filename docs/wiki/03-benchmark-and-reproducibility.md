# 03 - Benchmark Metrics & Experimental Reproducibility

> **Scientific Core**: AI-DB-Creator is built as a scientific research platform to benchmark and compare LLM relational database schema generation and population capabilities.

---

## 📐 Benchmark Evaluation Metrics

1. **3NF Structural Integrity (%)**:
   - Evaluates functional dependencies \(X \to Y\) across generated tables.
   - Measures insertion, update, and deletion anomaly risks.
   - A schema is 100% 3NF compliant if every non-trivial functional dependency \(X \to Y\) satisfies either \(X\) is a superkey or \(Y\) is a prime attribute.

2. **Relationship Precision, Recall & F1-Score**:
   - Compares generated Foreign Key (FK) constraints against ground-truth domain models across benchmark scenarios (`E-Commerce`, `Hospital Management`, `University Registrar`, `Fleet Logistics`).
   - \(\text{F1} = 2 \times \frac{\text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}}\).

3. **Cell Precision & Population Provenance**:
   - Assesses populated database rows generated by LLMs against SQL check constraints and domain rules.
   - Provenance tracking tags each row with LLM prompt execution metadata (`run_id`, `temperature`, `prompt_hash`, `timestamp`).

---

## 👥 Human-in-the-Loop Expert Evaluation

- **Likert Scale (1 to 5)**:
  - `1`: Scarso (Incompleto / Inaccurato)
  - `2`: Sufficiente
  - `3`: Buono
  - `4`: Molto Buono
  - `5`: Eccellente (Pronto per Produzione)
- **LaTeX Export Capability**:
  - `GET /api/benchmark/export-latex` converts user votes, confidence metrics, and comparative LLM performance into publication-ready LaTeX tables for academic submission.

---

## 🔒 Provenance & Reproducibility Hashes

To guarantee scientific rigor, every benchmark run generates an immutable JSON manifest:
- **`run_id`**: Cryptographic SHA-256 identifier based on input prompt + configuration.
- **Manifest Location**: `backend/projects/{project_id}/manifests/`
- **Hash Integrity**: `sha256_text(prompt)` and `sha256_text(schema_json)` recorded in database.
