# Manual Condition Protocol (RQ0)

> **DRAFT / UNAPPROVED — ETHICS REVIEW PENDING.** Tool choice, tutorial, facilitator policy and equivalence checks require approval and freeze before participant use.

## Allowed Environment

Participants receive the same source documents, task brief, target output requirements, tutorial duration, and task time limit as the AI-assisted groups. They may use one preselected conventional visual relational-database tool and its built-in documentation. Generative AI, automatic schema generators, pre-built schemas, copied SQL, and help from another person are prohibited.

Freeze and record the manual tool name, exact version, extensions, default settings, tutorial, and export format before recruitment. Do not permit participants to choose different tools after randomisation.

## Required Output

Each participant submits:

- relational schema with tables, columns, types, primary keys, foreign keys and constraints;
- populated database or SQL export;
- completion status and exported artifact hash;
- task start/end timestamps;
- Raw NASA-TLX and SUS responses.

The same automated RQ1/RQ2 evaluators and blind expert rubric are applied to all three conditions. Evaluators receive pseudonymous artifacts without condition labels.

## Assistance and Deviations

The facilitator may resolve only environment failures and reread the written task instruction. Conceptual database help is not provided. Record every help request and facilitator intervention with category and duration. A prohibited-tool use, unrecoverable environment failure, or material facilitator assistance is marked as a protocol deviation before outcome analysis.

## Fairness Checks

- Equal total tutorial time across conditions.
- Equal task time limit and source materials.
- Equivalent hardware and display configuration where sessions are supervised.
- Manual-tool operations needed for the task must be demonstrated in its tutorial just as AI-DB-Creator operations are demonstrated for assisted groups.
- Completion time includes export and submission in every condition.
