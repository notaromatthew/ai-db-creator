# Brief dei workstream

Un file per workstream del piano (`<id>-<titolo>.md`): obiettivo, file toccati, criteri di accettazione, divieti.
Ogni agente lavora in un proprio branch `agent/<nome>-<id>` e cartella di lavoro; integra solo il coordinatore, che rilegge sempre il diff.
I divieti comuni (commit, apply, Coolify/GCP reali, segreti) valgono per tutti: elenco in `docs/ops/azioni-con-sua-approvazione.md`.
