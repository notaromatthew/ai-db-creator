# Three-Arm Instructions and Equivalence Checklist — DRAFT / UNAPPROVED

> Training and task materials are placeholders until pilot review and ethics approval. The task goal, source documents, time limit, hardware and outcome requirements must be equivalent across arms; only the assigned intervention differs.

## Common task brief

Create and populate a relational database representing all source-supported entities, attributes and relationships in the supplied documents. Define appropriate types, primary/foreign keys and required constraints. Submit a valid export within `[time limit]`. Do not invent facts. Use only assigned tools and supplied documentation. Facilitators may resolve environment faults or reread instructions but cannot provide database-design advice.

## Manual tutorial

Demonstrate project creation, table/column creation, types, PK/FK/constraints, data entry/import, inspection and export in the frozen conventional tool. Prohibit generative AI, schema generators, copied solutions and external help. Do not demonstrate the study solution.

## AI-Only tutorial

Demonstrate document upload, generation, status/error interpretation and export. The participant may request generation but cannot visually edit or validate the proposed schema beyond actions explicitly exposed in this arm. Freeze whether regeneration is allowed and its count. Do not describe hidden features available in the Interface arm.

## AI + Interface tutorial

Demonstrate upload/generation plus schema review, renaming, adding/removing tables or columns, constraints/relationships, accepting/rejecting suggestions, reviewing populated data and export. Explain that suggestions can be wrong and require judgement.

## Manipulation and comprehension checks

Before task start, ask participants to identify the allowed tools, time limit and submission requirement. Failure triggers one neutral rereading, not exclusion. After task, record perceived AI involvement and whether validation/editing was available. Use checks diagnostically and as prespecified per-protocol sensitivity variables, not as post-outcome exclusion rules.

## Facilitator checklist

Confirm consent version, assignment display, clean workspace, clock synchronisation, frozen release/dataset/tutorial, no prior artifact, start/end events, interventions, outage codes, valid export hash, questionnaires and debrief. Never reveal condition hypotheses or evaluate performance during the session.
